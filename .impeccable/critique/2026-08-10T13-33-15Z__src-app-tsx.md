## Design Specificity Verdict

**LLM assessment**: Partially authored for MolCrafts, not fully interchangeable SaaS. Domain DNA is real (Moko glyphs, MoleculeOverlay, FAIR/agent/contract language, Application → Infrastructure → Specification catalog, forest/cream/cyan). Chrome still reads as polished OSS/SaaS essay landing: uppercase eyebrows, glass sticky nav, staggered fades, gradient wordmark, equal path cards. Cooler refinement is available without redesign; identity currently splits scientific forest/cream vs AI-product cyan/purple glow.

**Deterministic scan**: Official homepage TSX set returned **0** detector findings (exit 0, `[]`). Engine is healthy (verified with synthetic hits). Misses are structural: gradient text lives in `src/index.css` as `.gradient-text-primary` / `.premium-text-primary` (contextual scan: **2× gradient-text** at index.css:254, :274). Hex accents (`#03a3d7`, `#a855f7`) and `text-zinc-*` alone do not trip Tailwind-oriented rules. Em-dash / marketing-text analyzers do not run on component TSX.

**Visual overlays**: Not available — no browser inject path in this session (no Puppeteer / browser MCP for detect.js).

## Overall Impression

Above-average craft for an experimental brand site: sections have clear jobs, conversion honesty improved (no fake newsletter, docs gated, hero aimed at packages). Still long and same-y after Hero: three essay blocks delay the tangible product surface; catalog dumps ~15 entries; Newsletter + Cta are twin thin strips instead of a decisive end.

Actual order: Hero → WhatWeDo → Manifesto → Approach → EcosystemArchitecture → Sponsors → Participate → Newsletter → Cta (+ Footer).

## Priority Issues

### [P0] Primary path delayed and under-staged
- **What**: Hero CTA to `#projects` sits after WhatWeDo + Manifesto + Approach.
- **Why**: Visitor investment peaks late; product proof arrives after philosophy wall.
- **Fix**: Keep copy; tighten pre-catalog vertical rhythm; stronger Projects chapter break; optional sticky jump without new words.
- **Suggested**: `$impeccable layout` + `$impeccable distill`

### [P1] Section template monotony kills hierarchy
- **What**: Same eyebrow + light H2 + muted body across ~7 blocks.
- **Why**: Principles feel equal to Support and Updates; no scroll peaks.
- **Fix**: Differentiate density — denser Projects, quieter Support, stronger end panel.
- **Suggested**: `$impeccable typeset` + `$impeccable quieter` (mid) + `$impeccable bolder` (Projects/end)

### [P1] Catalog choice overload
- **What**: ~15 entries, mixed statuses, no visual "start here".
- **Why**: Working-memory and minimal-choices failures for first-timers.
- **Fix**: Lead shipping apps larger; de-emphasize in-dev; optional compact stack cue above grid.
- **Suggested**: `$impeccable distill` + `$impeccable layout`

### [P2] Brand accent split
- **What**: Forest tokens + hero cyan hex + newsletter purple + zinc body on cream.
- **Why**: Undercuts cool cohesion; detector missed hex/CSS because of class indirection.
- **Fix**: Route display accents through brand tokens; light-mode body via muted/foreground.
- **Suggested**: `$impeccable colorize` + `$impeccable polish`

### [P2] Weak peak-end pair
- **What**: Newsletter + Cta are isomorphic icon+link rows.
- **Why**: Last impression is another soft strip, not install confidence.
- **Fix**: One decisive close (docs/install primary, releases secondary) without rewording.
- **Suggested**: `$impeccable delight` + `$impeccable bolder`
