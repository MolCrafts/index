# Project knowledge

This directory contains passive, internal context for agents working on
`molcrafts-index`. It outlives individual features.

- `law.md` is the single non-overridable rules file.
- `notes.md` records durable project facts and evolving decisions.
- `architecture.md` is the project blueprint populated by `$mol:map`.
- `open-questions.md` records unresolved harness or project decisions.

Active implementation specs do not belong here; they live in
`.claude/specs/` and are removed when their work is complete.
